## Context

A complete visual identity system for a Berlin-based architecture firm. The challenge was distilling brutalist philosophy into a mark that could live across digital and physical mediums.

## Process

The first sketch happened on a napkin. From there, a hundred iterations — each one stripping something away until only the essential remained.

## This project required

- Visual restraint
- Systems thinking
- Material sensitivity
